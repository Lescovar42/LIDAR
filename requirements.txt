#   py -3.12 -m venv .venv

#
# GPU training (NVIDIA RTX 2060, Turing, CUDA 12.6 driver or newer required):
#   The training machine has an RTX 2060, so torch below is pinned to the
#   CUDA 12.6 build (2.13.0+cu126) instead of the CPU-only build. The
#   --extra-index-url line lets pip pull that one wheel from the PyTorch
#   index while everything else still resolves from PyPI as normal.
#   Verify after install with:
#     python -c "import torch; print(torch.cuda.is_available(), torch.cuda.get_device_name(0))"
#   If this ever runs on a machine without an NVIDIA GPU (e.g. this dev
#   machine, which has an AMD Radeon 780M), replace the two torch lines with
#   the CPU wheel instead:
#     torch==2.13.0
#   train_baseline.py auto-detects cuda vs cpu at runtime either way, and
#   --device lets you override the choice explicitly.
#
# Tkinter note that pip cannot express:
#   oregon/diagnostics/qc_patch_viewer.py needs tkinter, which ships with the
#   Python installer rather than pip. Install Python from python.org with the
#   "tcl/tk and IDLE" option enabled, or the viewer exits with a message.
